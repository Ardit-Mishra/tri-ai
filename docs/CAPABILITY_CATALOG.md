# Tri-AI Capability Catalog

Tri-AI is a verification-gated agent operating system for building software,
research workflows, and business systems. It should gain capabilities through
reviewed adapters, not by running every tool an agent can find. A capability
can provide planning, retrieval, browsing, design, voice, or memory; it does
not gain authority to push, deploy, spend money, access credentials, or accept
its own work.

## Requires a pinned upstream before installation

The following names do not identify one unambiguous repository. They remain
catalog entries until an owner/URL, license, install method, and permission
surface are reviewed: AgentMemory, OpenViking, agency agents, Voicebox,
Graft, OpenMontage, Codebase Memory MCP, Agent Reach, Agent Canvas, Archify,
OpenMAIC, Ponytail, agent-skills, VoiceStudio, Orca, MiniMind, OpenHands, and
the Anthropic cybersecurity skills.

For each candidate, the admission record must include: immutable upstream
revision, license, network/process/credential permissions, local install path,
tests, and the exact Tri-AI adapter boundary. Voice capabilities additionally
need an explicit consent and retention policy. Browser capabilities require a
domain and download policy. Memory capabilities cannot execute tasks or mutate
procedural rules without a recorded operator approval.

This keeps the portfolio useful for building sites, apps, automations, and
business workflows while preventing a plugin list from quietly becoming an
unreviewed execution surface.
